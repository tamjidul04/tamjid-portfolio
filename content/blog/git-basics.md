tags: ["Git"]

```bash
git status                 # see what changed
git switch -c my-feature   # start a new branch
git add .                  # stage your changes
git commit -m "Add login"  # save them
git push -u origin my-feature
```

Check `git status` before staging, so you don't commit files by mistake.
